# Apple Icon Composer — six appearance authoring sources

Sources incluses :
- `Default.png`
- `Dark.png`
- `Clear-Light.png`
- `Clear-Dark.png`
- `Tinted-Light.png`
- `Tinted-Dark.png`

`Mono-Tinted.png` est conservé comme source grayscale générique. Les fichiers `AppIcon.appiconset` restent compatibles Xcode avec Any, Dark et Tinted ; les variantes Clear/Tinted Light/Dark sont des sources destinées à Apple Icon Composer pour finaliser le fichier `.icon`.
